description: Write a SOAP-format veterinary clinical note for a patient visit
---

Write a complete SOAP-format veterinary clinical note based on the information provided.

The note should include the following sections:

**S — Subjective**
- Chief complaint / reason for visit
- Patient signalment (species, breed, age, sex, reproductive status)
- Relevant history (duration of signs, progression, prior treatments, diet, lifestyle)
- Owner observations and concerns

**O — Objective**
- Vital signs: temperature, pulse rate, respiratory rate, weight, body condition score
- Physical examination findings (systematic, head-to-tail)
- Any abnormalities noted on exam
- Results of any in-house diagnostics (bloodwork, urinalysis, cytology, imaging)

**A — Assessment**
- Primary diagnosis or differential diagnoses (ranked by likelihood)
- Problem list
- Clinical reasoning supporting the diagnosis

**P — Plan**
- Diagnostic plan (further tests ordered)
- Treatment plan (medications with dose, route, frequency, duration)
- Surgical or procedural plan if applicable
- Client education provided
- Recheck recommendations and monitoring parameters
- Prognosis

Format the note professionally, as it would appear in a veterinary medical record. Use standard veterinary abbreviations where appropriate (e.g., BAR, QAR, TPR, SID, BID, TID, QID, PO, SQ, IM, IV). Be thorough, precise, and medically accurate.
